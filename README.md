# NEXFORGE NUTRITION — Présentation 3D

Présentation technique et créative du projet : identité originale, concepts de produits, navigation mobile et scène 3D interactive.

Aperçu local conservé dans un dépôt privé. GitHub Pages est désactivé. L’hébergement retenu pour la boutique complète est Render, après connexion du compte.

Ce dossier contient uniquement les fichiers nécessaires au navigateur. Le projet Django complet est conservé dans son dépôt privé distinct. Aucune vente, prise de commande, collecte de données clients ou authentification n’est disponible dans cette présentation.

Three.js est fourni sous licence MIT, avec sa licence et sa provenance dans `static/vendor/three/`.
