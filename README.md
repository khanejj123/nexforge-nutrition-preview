# NEXFORGE NUTRITION — Présentation 3D

Présentation technique et créative du projet : identité originale, concepts de produits, navigation mobile et scène 3D interactive.

[Ouvrir la présentation](https://khanejj123.github.io/nexforge-nutrition-preview/)

Ce dépôt contient uniquement les fichiers publics nécessaires au navigateur. Le projet Django complet est conservé dans un dépôt privé distinct. Aucune vente, prise de commande, collecte de données clients ou authentification n’est disponible dans cette présentation.
